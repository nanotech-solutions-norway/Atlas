- activate approved Atlas sources and resolve authority before generation;
- use exact canonical page-tree names plus `v1` and `v2`;
- generate two alternatives with identical facts and different information architecture;
- read and score every card before Figma transfer;
- apply hard veto gates for unsupported claims, canonical conflicts, false implementation status, prohibited wording, sensitive intake, unapproved legal/commercial content and provider ambiguity;
- select one canonical Gamma ID per page/version;
- create a source-to-slide map before Figma work;
- extract the latest page-specific measurement source rather than universalising Business v1 geometry;
- validate the actual `SLIDE_GRID > SLIDE_ROW > SLIDE` tree;
- separate structural, measurement, visual, content/claim and publication validation;
- treat Figma completion as design evidence, not Wix or launch completion.
