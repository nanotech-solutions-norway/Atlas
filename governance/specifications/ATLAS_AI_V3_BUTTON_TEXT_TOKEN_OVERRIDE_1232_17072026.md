## Operational rule for future recreation

1. Read the current Gamma CTA wording exactly.
2. Use Roboto SemiBold 24 px with 30 px line height.
3. Center the text horizontally and vertically within the button frame.
4. Use 78 px button height unless a later explicit instruction changes the component.
5. Keep a 16 px gap between paired buttons.
6. Use standard 480/320 px widths where the wording fits.
7. Use a documented content-fit width for long wording; do not reduce text below 24 px merely to fit.
8. Validate zero wrapping, clipping, overlap and out-of-bounds controls.
