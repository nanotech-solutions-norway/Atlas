# Atlas AI tax control pack

This folder contains the controlled MVA/VAT readiness records for Atlas AI.

## Current files

- `ATLAS_MVA_FINALISATION_REGISTER_25072026.md`
- `ATLAS_MVA_OFFER_JURISDICTION_MATRIX_25072026.csv`

## Authority and status

- The standard Norwegian rate of 25% is the approved working baseline for domestic taxable Atlas digital, IT, consultancy, setup and managed services.
- Final treatment remains `PENDING_ACCOUNTING_AND_TAX_REVIEW` until each offer, customer type, jurisdiction, bundle, billing event, refund event and provider purchase has an approved tax treatment.
- Tax approval does not enable publication, purchase, checkout or production availability.
