## Mandatory instruction

When recreating or updating Atlas AI Figma Slides, use the following default CTA/button typography:

- Font: Roboto SemiBold
- Size: 24 px
- Line height: 30 px
- Horizontal alignment: center
- Vertical alignment: center
- Button height: 78 px
- Border: 2 px
- Radius: 4 px
- Paired-button gap: 16 px

This rule supersedes every earlier prompt, report, specification or validation that states 36 px CTA text.

## Width rule

- Use the canonical 480 px primary and 320 px secondary widths when the Gamma wording fits.
- Preserve approved content-fit widths already used in a deck.
- For new long CTA wording, increase width within the 1712 px content frame rather than reducing the text below 24 px.
- Preserve the 16 px inter-button gap.

## Source fidelity

Gamma remains authoritative for the button wording and primary/secondary hierarchy. Do not rewrite CTA wording, add a destination or activate a hyperlink unless explicitly requested.

## Required validation

For every button:

1. verify Roboto SemiBold 24 px;
2. verify 30 px line height;
3. verify vertical and horizontal centring;
4. verify no wrap, clipping or overlap;
5. verify the text container matches the button frame;
6. verify frame height, radius, border and gap;
7. inspect the first and final CTA slides visually.
