# Atlas Naming Conventions — 12:45, 01.06.2026

## Repository paths
- `docs/` — architecture, governance, runbooks and registers.
- `schemas/` — CMS fields, route contracts and enum definitions.
- `cms-seeds/` — import-ready CSV/JSON seed packs.
- `velo/` — Wix Velo source and deployment notes.
- `qa/` — launch and regression validation assets.
- `future-azure/` — inactive secure-runtime contracts and IaC placeholders.
- `assets/` — static website CSS, JavaScript and images.

## Branches
- `main` — approved source of truth and deployment branch.
- `feature/*` — implementation work.
- `chore/*` — governance, maintenance and documentation.
- `release/*` — controlled release preparation.
