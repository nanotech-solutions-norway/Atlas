# GitHub Role in Atlas AI — 13:35, 04.06.2026

GitHub is the engineering governance and control plane for Atlas AI — not the main public website CMS and not the primary customer-facing runtime.

## Purpose

GitHub's purpose is to:

1. Act as source of truth for architecture decisions, naming rules, repository rules, release policy, implementation register, schemas, claims, and evidence.
2. Control website and package governance before Wix publication: sitemap, CMS schema, claims registry, bilingual content model, and public-vs-secure boundaries.
3. Synchronize Wix, Gamma, and future Azure work through page maps, CMS schemas, QA checklists, evidence links, and implementation status.

5. Support security and compliance through branch rules, PR templates, CODEOWNERS, release tags, secret scanning/push protection, dependency review, and audit evidence.

## Precise conclusion
