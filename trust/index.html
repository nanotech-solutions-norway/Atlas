Trust and risk posture

Commercially truthful AI delivery with clear risk boundaries.

Data rule

Do not submit confidential customer data, credentials, bank details, health records or sensitive personal data through public surfaces.

Output rule

AI output is advisory and may contain errors. High-impact decisions require human validation.

Customization rule

Customer specialization is additive and bounded; it does not overwrite the Atlas core governance model.

Secure mode rule

Managed Secure Mode is future premium delivery, not a current Azure production claim.
